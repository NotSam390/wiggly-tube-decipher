〰 Wiggly Tube
A translator for Wiggly Tube — its own alphabet made of symbols. Decode Wiggly Tube into plain text, or encode plain text into Wiggly Tube.
How to use

Decode: paste Wiggly Tube into the box and get plain English back
Encode: switch to encode mode and type normally to convert to Wiggly Tube
Click any letter in the alphabet table to insert it directly
